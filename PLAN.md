Crie uma aplicação web para controle de custos de produção de aromatizadores.

A aplicação deve ter uma área de cadastro de matéria-prima, onde o usuário possa cadastrar código, nome do produto, quantidade por embalagem, unidade de medida e valor pago pela embalagem. O sistema deve calcular automaticamente o custo unitário dividindo o valor da embalagem pela quantidade da embalagem.

A aplicação também deve ter uma área de cadastro de receitas. Em cada receita, o usuário deve informar o nome da receita, a quantidade final produzida e adicionar os materiais utilizados. Para cada material, o usuário deve selecionar ou digitar o código da matéria-prima cadastrada. O sistema deve buscar automaticamente o nome do produto, o custo unitário e permitir informar a quantidade utilizada na receita.

Para cada item da receita, o sistema deve calcular o valor gasto multiplicando a quantidade utilizada pelo custo unitário. No final da receita, o sistema deve somar todos os valores gastos e exibir o custo total de produção.

A aplicação também deve permitir informar uma margem de lucro em porcentagem e calcular automaticamente o preço sugerido de venda.

A interface deve ser simples, organizada e intuitiva, com tabelas para matéria-prima e receitas. Deve permitir adicionar, editar e excluir matérias-primas e itens da receita. Os dados podem ser salvos localmente no navegador usando localStorage.

Use o @prompt.xml  para o design-system limpo, responsivo e moderno.
